# 💪 FitLog

FitLog is a dark, responsive workout library and daily workout planning app.

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router
- REST API
- LocalStorage

## ✨ Features

- Browse workout library from the FitLog API
- View detailed workout information
- Add workouts to today's plan
- Save workouts for later
- Track planned exercises, minutes, and calories
- Mark workouts as done
- Remove workouts from the plan or saved list
- Sort workouts by duration, calories, and rating
- Responsive design for mobile, tablet, and desktop

## 🔗 API

Primary API:

https://api.abcz.workers.dev/api/fitlog

Alternative API:

https://api.api-store.workers.dev/api/fitlog

## 📱 Responsive Design

FitLog is designed to work across mobile, tablet, and desktop screen sizes.
